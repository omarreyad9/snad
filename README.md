# Muse

Flutter app covering these stories:
- Category & Product Browsing (Home, Catalog & Variants)
- Onboarding & Address Management (Welcome + Profile)
- Authentication (Supabase email/password: sign up, login, session, sign out)

## Run
```
flutter create .     # one time: generates android/ios (keeps lib/)
flutter pub get
flutter run
```
Supabase URL/key: lib/config/supabase_config.dart
